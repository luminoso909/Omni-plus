## 一、本轮范围与审查入口

本轮推进本地多模态前向、Mimi 波形链路，以及小样本 SFT 工程验收。主模型仍为 `OmniPlusOmni`，保留原有 Thinker、Bridge、Talker 的计算与权重键，不引入新的模型框架。

| 阶段 | 详细报告 | 实际验收范围 |
| --- | --- | --- |
| P2 | [P2.md](../stages/P2.md) | 真实冻结编码器、195 键 SFT 权重、四种混合输入前向 |
| P3 | [P3.md](../stages/P3.md) | Codec-only、八码本还原、新旧 logits/KV、完整停止与 WAV 回读 |
| P4 | [P4.md](../stages/P4.md) | 官方小样本划分、冻结特征、损失/梯度、训练和恢复 |

P2/P3 使用现成 SFT 权重验证链路，不能当作本项目重新训练出的能力。P4 小主干过拟合只验证训练设施；全尺寸分阶段 SFT 与完整数据下载另列待办。

本地主机最终检查为 144 项 pytest 全通过，无跳过；Ruff、源码格式、依赖、锁文件与打包检查通过。P4 训练 loss 从 16.80580 降至 5.63626，验证 loss 上升，结果只支持小样本工程过拟合。MPS 恢复权重最大差 4.91e-6，CPU 恢复对照精确一致。

## 二、相比原项目的补充与修改清单

对照范围为本地只读 `minimind-o` 的 `model/model_omni.py`、`dataset/omni_dataset.py`、`trainer/train_sft_omni.py`。只列本轮补充及本轮验证的既有修复，不将参考架构记作新算法。

| 编号 | 原项目参考方式 | 本次补充或修改 | 审查位置 |
| --- | --- | --- | --- |
| P2-01 | 外部编码器在 Omni 构造时加载 | 独立构造注册的冻结 Encoder，模型外提供 Dataset 回调 | `omni/models/encoders/model_encoders.py` |
| P2-02 | 冻结后设备/eval 生命周期需单独管理 | `.train()` 仍 eval，参数跟随 `.to()`，回调返回有效 CPU FP32 特征 | 同上；`tests/test_encoders.py` |
| P2-03 | frontend 默认存在随机 dither | dither=0，重复音频编码逐元素一致；图片 path/bytes 一致 | `scripts/check_p2.py` |
| P2-04 | 模态缺失/混合索引易被有效项拼接打乱 | 既有 list/None 路由保持原索引，本轮增加四组合、重排和单样本对照实测 | `scripts/check_p2.py`、`experiments/p2/` |
| P2-05 | 宽松加载可能保留随机参数 | SenseVoice encoder 与 Omni 分别严格加载，记录全部键和权重 SHA | Encoder 构造及 P2 报告 |
| P3-01 | Codec 与媒体处理分散在推理入口 | 独立冻结 Mimi、统一波形 IO，显式采样率和有理数重采样 | `omni/inference/codec.py` |
| P3-02 | delay/stop 常量散在训练/生成逻辑 | 新增独立可逆 delay/restore/mask，覆盖空/短序列与起点 | `omni/data/audio_alignment.py` |
| P3-03 | 可播放文件不足以证明码本时序 | 受控八码本生成测试；文本 EOS 后仍正确完成音频尾部 | `tests/test_codec.py` |
| P3-04 | Codec 误差和 Talker 输出易混合评价 | 先做 codec-only，再做同权重 logits/KV 与完整 TTS | `scripts/check_p3.py` |
| P3-05 | 触及步数上限的片段也可播放 | 记录实际停止步数；保留 run-01 截断记录，以 run-02 验收 | `experiments/p3/` |
| P4-01 | 数据入口直接读取完整本地 Parquet | 显式官方固定 revision 小样本收集，Range 字节预算，不回退整文件下载 | `scripts/collect_p4.py` |
| P4-02 | 行与媒体可能在不同任务或 split 重复 | 固定源行号，跨任务记录/逐媒体去重，再固定 64/8 划分 | `omni/data/prepare.py` |
| P4-03 | 运行中反复读取/编码原始媒体 | 冻结特征缓存，与最后一轮监督配对；元数据与模型输入分开 | `cache_split`、`scripts/prepare_p4.py` |
| P4-04 | 数据与模型易重复做 next-token shift | 维持数据侧唯一 shift，损失直接对齐 logits | `omni/training/losses.py` |
| P4-05 | stop 权重/八码本归一化硬编码 | 保留原定义，stop 权重可配置，码本数来自 Tensor 维度 | 同上；独立手算测试 |
| P4-06 | micro-batch 等权平均会偏置变长样本 | 按整个累积组的有效 Token 分母计算 CE | `train_step`、变长累积对照测试 |
| P4-07 | FP16 overflow 可能提前被梯度检查中断 | 交由 GradScaler 跳步/降 scale，区分更新尝试和成功更新 | `omni/training/sft.py` |
| P4-08 | checkpoint 恢复不一定覆盖完整随机数/采样位置 | 保存 model、optimizer、scaler、RNG、epoch/cursor，校验配置/冻结/缓存 SHA | `save_checkpoint`、`load_checkpoint`、训练入口 |
| P4-09 | 恢复时可能依赖原始初始化权重仍在 | checkpoint 自带权重，resume 不再读取初始化文件 | `scripts/train_sft.py` |
| P4-10 | 冻结标志不等于冻结更新已验证 | 实际更新一步，逐参数确认仅 vision projector 改变 | `tests/test_sft.py` |
| P4-11 | 新实验可能覆盖旧日志与结果 | 每次训练/恢复新建 run，保留 CSV、曲线和 step checkpoint | `scripts/train_sft.py` |
| ENG-01 | 媒体框架与基础文本环境混合 | media/encoders/plots/data 分成可选依赖，CPU CI 不装真实编码器 | `pyproject.toml`、CI |
| ENG-02 | 普通测试可能依赖真实模型或下载 | 普通 fixture/网络边界测试与真实验收脚本分开 | `tests/`、`scripts/check_p*.py` |
| ENG-03 | 跨平台文本换行转换可能改变原始日志 SHA | CSV 保留标准 CRLF 原始字节，Git 明确识别换行，指标与校验值不改写 | `.gitattributes` |

## 三、复现与事实边界

先安装本轮使用的可选依赖，再显式执行验收；所有真实资产均留在忽略目录或只读旧仓库。

```bash
source .venv/bin/activate
python -m pip install -e '.[dev,media,encoders,plots,data]'
HF_HUB_OFFLINE=1 HF_DATASETS_OFFLINE=1 python -m pytest -q
ruff check omni tests scripts
ruff format --check omni tests scripts
```

- CPU FP32 新旧数值对照采用 `rtol=1e-4, atol=1e-4`，不放宽容差。
- 完整数据下载、正式全尺寸训练、DDP/多机、理解准确率、ASR/听评及实时性均不由本轮工程烟测替代。
- 官方数据卡声明 Apache-2.0 与 GPL-3.0，未逐文件区分；本地子集不公开再分发。Mimi 本地转换资产为 CC-BY-4.0，分别保留归属。
- 旧仓库、个人 Notebook 和旧实验结果保持原样；不自动进入 P5 或推送远程。
