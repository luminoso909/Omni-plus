## 一、P3 目标与状态

已完成本地 Mimi codec-only 还原、八码本延迟/停止边界、旧版音频 logits 对照，以及现有 SFT 权重的文本→声学 codes→WAV 链路。没有训练、下载或修改旧 `minimind-o` 仓库。

最终验收为 `experiments/p3/run-02.json`。`run-01.json` 保留首轮 96 步预算烟测；首轮输出 7.04 秒，预算可能截断音频尾部，不作为完整停止验收。

## 二、实现与接口

| 文件 | 作用与形状 |
| --- | --- |
| `omni/inference/codec.py` | `load_audio` 读取 path/bytes/Tensor，混合声道并重采样为 CPU float32 `[samples]`；`save_audio` 写 PCM16 WAV |
| 同上 `MimiCodec` | 外部注入标准 HF 模型，冻结并保持 eval；`encode` 返回 `[1,8,F]`，`decode` 返回单声道 `[samples]` |
| `omni/data/audio_alignment.py` | 第 i 路从 `start+i` 放入 codes，默认 `start=1`；每路尾部追加 stop，恢复时只接受声学 ID |
| `scripts/check_p3.py` | 显式离线真实资产验收，新 run 不覆盖已有 JSON/WAV；参考代码以内存编译方式执行 |
| `tests/test_codec.py` | 空/短序列、不同起点、八码本还原、冻结生命周期、特殊 ID、波形 IO 与受控生成顺序 |

项目原有 Dataset 与 `OmniPlusOmni.stream_generate` 的延迟约定保持一致。新增受控单测让文本先结束，再检查八路音频分别延迟、停止及恢复，避免仅凭可播放 WAV 推断码本顺序正确。

## 三、资产与运行条件

- 设备/精度：CPU FP32，线程数 4，seed=42；Python 3.12.14、PyTorch 2.15.0、Transformers 4.57.6。
- Mimi：只读使用 `../minimind-o/model/mimi/`，模型卡明确为 Kyutai Mimi 的本地 FP16 转换版本，本轮以 FP32 加载；沿用原作者归属及 CC-BY-4.0。
- Omni：只读使用 `../minimind-o/out/sft_omni_768.pth`，先检查源 embedding/head 相等，再对新旧模型严格加载全部 195 键。
- Codec 输入：`../minimind-o/output_benchmark/cer_00.wav` 的前 2 秒，24kHz 单声道。
- 旧版参考 commit、两份源代码、权重、模型卡和音频 SHA-256 均记录在 JSON。
- 两次 HF 加载均使用 `local_files_only=True`，并设置 Hub/Datasets 离线环境变量。

参考对照只执行旧文本核心与 Omni 类定义，音频/视觉编码器在本次对照中不构造；外部媒体编码器在 P2 独立验收。没有复制参考模型核心到项目源码。

## 四、实测结果

| 检查 | run-02 结果 |
| --- | --- |
| Mimi 严格加载 | missing/unexpected/mismatched/error 均为空 |
| Codec-only codes | `[1,8,25]`，ID 范围 4–2039 |
| 延迟排列及恢复 | `[1,8,34]` → 原始 codes，逐元素精确一致 |
| Codec-only 波形 | 原始/还原均 48000 点，2.00 秒，有限且非静音 |
| 逐样点重建 MSE / SNR | 0.00372659 / 4.49581 dB，未做时延校正 |
| 新旧文本 logits 最大绝对差 | 2.48e-5 |
| 新旧音频 logits 最大绝对差 | 2.86e-5，形状 `[1,8,8,2112]` |
| 新旧 Thinker+Talker KV 最大绝对差 | 2.07e-5 |
| 数值容差 | `rtol=1e-4, atol=1e-4`，未放宽 |
| 文本→语音 | 256 步上限，实际 134 次 forward 后文本和八码本均停止 |
| 生成 codes / 波形 | `[1,8,125]`，240000 点，即 10.00 秒 |
| WAV 文件 | 24kHz、单声道、PCM16，保存后成功回读，长度一致 |
| 普通单元测试 | 20 passed，3.22 秒；Ruff 静态与格式检查通过 |

实际文本输出：春天是一年中最美的季节之一，花开满园，鸟语花香，温暖的阳光和微风拂面，让人心情愉悦。

波形位于本地忽略目录：

- [Codec 原始片段](../../outputs/p3/run-02/codec-source.wav)
- [Codec 重建片段](../../outputs/p3/run-02/codec-reconstruction.wav)
- [Omni 生成音频](../../outputs/p3/run-02/omni-generated.wav)

逐样点 SNR 只记录 codec-only 误差，不等于感知音质或 ASR 分数。本轮验证有效 PCM 波形和停止/顺序，没有进行人工听评、ASR 或说话人相似度评测，也未宣称实时性能。

## 六、复现与下一阶段

安装项目的 `media` 额外依赖并激活 `.venv` 后，在项目根目录执行：

```bash
python -m pytest -q tests/test_codec.py
ruff check omni/inference omni/data/audio_alignment.py tests/test_codec.py scripts/check_p3.py
HF_HUB_OFFLINE=1 HF_DATASETS_OFFLINE=1 PYTHONDONTWRITEBYTECODE=1 python scripts/check_p3.py --output-dir outputs/p3/review-01 --report experiments/p3/review-01.json
```

再次执行时使用新的输出目录与报告名。普通 pytest 使用极小临时模型和内存 WAV，不读取大型权重；真实权重验收只由显式脚本启动。

P4 接续 Dataset/Collator、损失、训练与恢复的一致性检查。本阶段结果不代表完成新模型训练或语音质量评测。
