## 一、P1 文本模型验收

本轮复用现成模型和 tokenizer，没有训练 tokenizer、执行优化器更新或进入 P2。MiniMind 用自研 Thinker 验收；Qwen3 使用官方 Transformers 实现，两条结果分开记录。

两套资产的真实验收均通过，原始运行摘要、生成 Token 与文件校验值保存在 `experiments/p1/`。

本轮环境：macOS arm64、Python 3.12.14、PyTorch 2.15.0、Transformers 4.57.6；MPS 可用。两个验收脚本均固定 CPU 线程数为 4。

### 1 本地资产

| MiniMind Dense/MoE | `weights/minimind/llm_768.pth`、`llm_768_moe.pth` | `tokenizers/minimind/` | 自研 `OmniPlusForCausalLM` |
| Qwen3-0.6B | `weights/qwen3-0.6b/`，官方完整 HF 目录 | 同一 HF 目录 | 官方 `Qwen3ForCausalLM` |

MiniMind 来自只读旧仓库，额外保留上游权重卡与 LICENSE。`minimind-assets.json` 记录原始路径、参考 Git commit、参考源码 SHA-256、源/目标资产 SHA-256；复制前后内容一致。

Qwen3 固定官方 revision `c1899de289a04d12100db370d81485cdf75e47ca`。不使用 GGUF、MLX 量化缓存或第三方重新打包权重。下载与离线验收为两个明确操作，验收入口不会自动联网下载。

### 2 MiniMind 真实权重对照

两侧均在 CPU FP32 运行，固定 seed=42、dropout=0；数值判定使用 `rtol=1e-4、atol=1e-4`，没有为通过测试放宽容差。

| missing/unexpected keys | 均为空 | 均为空 |

| HF 保存/加载回环差异 | 0 | 0 |
| Cache 开关贪心生成 Token | 一致 | 一致 |

全部 Block 输出、KV（转换布局后）、单 Token/双 Token Decode、padding 和因果前缀均通过。原始 embedding/head 先确认相等，避免权重绑定掩盖源文件冲突。

MoE 各层 Router 概率与 Top-1 专家选择通过参考对照；当前输入的各专家命中数已记录。共享参数为 19,110,144，每 Token 激活专家的参数预算为 44,826,624，合计 63,936,768。这里按完整共享张量计数，不等于 FLOPs、显存或速度测量。

梯度检查只启用首层 Q 投影，以及 MoE 的首层 Router，其余参数冻结以控制双模型内存。Dense Q 投影梯度最大差约 4.17e-6；MoE Q 投影约 4.47e-7、Router 约 2.80e-6，辅助损失差约 4.66e-10。没有执行优化器，不宣称完整参数梯度已对照。

Tokenizer 长度 6400，最大 Token ID 6399，BOS/EOS/PAD 分别为 1/2/0。中文提示词生成已执行，24 个新 Token 的实际结果见 JSON；这是运行烟测，不是聊天质量或效果评分。

### 3 Qwen3 官方文本基线

官方完整目录共 10 个文件，包含 Safetensors、配置、tokenizer、模板、模型卡与 Apache-2.0 LICENSE。权重大小 1,503,300,328 bytes，SHA-256 为 `f47f71177f32bcd101b7573ec9171e6a57f4f4d31148d38e382306f42996874b`，与官方 LFS 元数据一致；其余文件的大小和本地 SHA-256 逐一记录。

| 检查 | 实测结果 |
| --- | --- |
| 标准 HF 加载 | missing/unexpected/mismatched/error 均为空 |
| Tokenizer | 长度 151669，最大 ID 151668；中英文编码/解码一致 |
| 模型词表 | 151936 行，允许对齐 padding；输入与输出权重绑定 |
| Tokenizer 特殊 Token | BOS 无，EOS 151645，PAD 151643 |
| CPU FP32 前向 | logits `[1, 1, 151936]`，全部有限 |
| MPS FP16 生成 | 中英文均通过，分别生成 28/19 个 Token（含 EOS） |

全程从本地目录加载，使用 `local_files_only=True` 及离线环境变量。固定 seed=42、贪心生成、最多 32 个新 Token，模板传入 `enable_thinking=False`。模板中的空 `<think>...</think>` 来自官方 non-thinking 格式，不代表执行了思考生成。

官方模型 config 的 BOS 为 151643；tokenizer 未声明 BOS，聊天输入按官方模板构建，不另外插入 BOS，也没有修改官方文件。

显式设置 `use_model_defaults=False`，避免官方 generation config 中的随机采样默认值覆盖贪心设置；普通测试禁止调用 `torch.multinomial`，验证此行为。

中文实际输出：语言模型是一种能够理解和生成文本的AI系统，它通过学习大量文本数据来模仿人类的思维方式和语言表达方式。

英文实际输出：A language model is a type of artificial intelligence model that can understand and generate human language.

这是短提示词烟测，不作为模型质量、速度或多模态能力评测。完整模板、Token ID、实际设备/精度和耗时见 `qwen3.json`。

### 4 复现命令

在项目根目录激活 `.venv` 后执行：

```bash
# 普通单元测试：不加载真实大权重，不联网下载
HF_HUB_OFFLINE=1 HF_DATASETS_OFFLINE=1 python -m pytest -q
ruff check omni tests scripts
ruff format --check omni tests scripts

# MiniMind：严格加载、参考对照、HF 回环及文本生成
HF_HUB_OFFLINE=1 HF_DATASETS_OFFLINE=1 python scripts/check_minimind.py --variant dense
HF_HUB_OFFLINE=1 HF_DATASETS_OFFLINE=1 python scripts/check_minimind.py --variant moe

# Qwen3：仅加载已有本地 HF 目录
HF_HUB_OFFLINE=1 HF_DATASETS_OFFLINE=1 python scripts/check_qwen3.py --model-dir weights/qwen3-0.6b --output experiments/p1/qwen3.json
```

MiniMind 也可用 `--variant all` 一次检查两种权重。Qwen3 可显式指定 `--device cpu`；默认要求 MPS 可用，不会静默换设备。普通 pytest 使用 tiny/temp fixture，真实资产验收由上面的脚本显式执行。

### 6 事实边界与后续

- 保持模型核心和 `OmniPlusOmni` 命名；脚本直接调用标准权重接口，不增加模型注册体系。
- MiniMind 真实参考对照在 CPU FP32；不将它描述为真实权重的 MPS 一致性测试。
- Qwen3 是官方文本基线，未接入自研 Thinker、Bridge 或 Talker。
- P2–P4、正式训练、Qwen Adapter 与 Qwen3.5-0.8B 均保留为未启动待办。
- 资产由 `.gitignore` 排除；只提交小规模清单、指标、脚本和文档，不提交权重或 tokenizer 目录。
