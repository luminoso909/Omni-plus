## 一、目标与范围

为已有 `OmniPlusOmni` 接入本地 SenseVoiceSmall 与 SigLIP2，验证真实音频/图像特征到文本、音频 logits 的前向链路。冻结编码器在模型外显式创建，直接作为 `OmniDataset` 的回调，不在 Omni 构造函数中加载或下载资源。

本阶段验证输入、冻结状态、混合 batch 索引、有效长度、padding 与前向数值；不把运行成功描述成图像/语音理解准确率。

## 二、实现与张量约定

| 接口 | 输入 | 输出 |
| --- | --- | --- |
| `SenseVoiceEncoder(path)` | 本地目录 | 注册的冻结 `encoder`、`frontend` |
| `SenseVoiceEncoder.forward` | 音频路径、bytes，或带采样率的波形 Tensor | CPU FP32 `[有效帧数, 512]` |
| `SiglipEncoder(path)` | 本地模型和 processor 目录 | 注册的冻结视觉编码器 |
| `SiglipEncoder.forward` | 图片路径或 bytes | CPU FP32 `[64, 768]` |
| `Projector.forward` | `[..., D_in]` | `[..., D_thinker]`，Token 数不变 |

音频统一为 16 kHz 单声道，fbank 在 CPU FP32 计算；SenseVoice 编码器根据返回的有效长度裁剪。视觉按本地 processor 转换 RGB、缩放及归一化。编码器计算跟随 `.to(device, dtype)`，回调结果统一回到 CPU FP32，供 Dataset/Collator 整理；调用 `.train()` 也保持冻结模块 eval。

SenseVoice fbank 的 dither 设为 0，避免评估和缓存时引入随机抖动。仅做确定性预处理，不进行音频变速或 SpecAugment。

## 三、测试与运行条件

普通测试使用小型替身模块，不下载模型或读取真实权重：

```bash
HF_HUB_OFFLINE=1 HF_DATASETS_OFFLINE=1 python -m pytest -q tests/test_encoders.py
ruff check omni/models/encoders tests/test_encoders.py scripts/check_p2.py
```

真实验收须先安装项目 `media,encoders` 可选依赖，并保留已收集的 MiniMind tokenizer：

```bash
HF_HUB_OFFLINE=1 HF_DATASETS_OFFLINE=1 PYTHONDONTWRITEBYTECODE=1 python scripts/check_p2.py --device cpu
```

默认只读 `../minimind-o`；通过 `--reference-root` 指定其他本地位置。脚本按时间创建新的 `experiments/p2/<run_id>/report.json`，显式 `--output` 也不覆盖已有文件。

验收使用本地 `SenseVoiceSmall/model.pt`、`siglip2-base-p32-256-ve/model.safetensors`、`sft_omni_768.pth`，以及 `dataset/eval_omni` 中的中文 MP3 和橘猫图片。SFT 权重原名严格加载全部 195 键；SenseVoice 单独对 `encoder.*` 权重严格加载，避免第三方加载器保留未加载随机参数。

## 四、结果与证据

普通编码器测试 3 项通过，覆盖冻结与注册、有效输出长度、dtype/device、只读本地路径、RGB 与 patch 顺序，以及禁止隐式下载。

真实资产验收在 CPU FP32、seed=42、4 个 CPU 线程下通过，报告为 `experiments/p2/20261104T065000931843Z/report.json`。四种 batch 组合为纯文本、仅音频、仅图片、音频加图片。

| 检查 | 实测结果 |
| --- | --- |
| SFT 权重严格加载 | 195 键；missing/unexpected 均为空 |
| SenseVoice 特征 | `[23, 512]`，重复编码完全相同 |
| SigLIP2 特征 | `[64, 768]`，图片路径/bytes 编码完全相同 |
| 混合 batch 文本 logits | `[4, 119, 6400]`，全部有限 |
| 混合 batch 音频 logits | `[4, 8, 119, 2112]`，全部有限 |
| 单样本与混合 batch | 文本最大绝对差 2.19e-5，音频 4.29e-5 |
| 重排样本后的逐样本结果 | `rtol=1e-4, atol=1e-4` 下通过 |
| padding 区标签 | 文本和音频均为 `-100` |
| 编码器生命周期 | 注册、冻结、eval 和有效长度检查通过 |

全部数值比较保留原容差，没有自动放宽阈值。各样本有效 Token 数依次为 32、55、96、119；JSON 保留每行差异与真实资产 SHA-256。

FunASR 1.4.17 的加载器会打印通用的 `download models from model hub: ms` 日志；本次传入的是已存在的绝对目录，实际读取本地配置和 `model.pt`，没有下载模型。HF 组件使用 `local_files_only=True`，验收同时启用离线环境变量及禁止字节码写入。

## 五、问题与局限

- 外部编码器是成熟预训练模型，不在本项目重新实现其网络。
- 本地 SigLIP2 是裁剪出的 Vision Encoder，实际加载类型为 `SiglipVisionModel`；未使用完整图文模型。
- 没有执行理解质量基准、增强实验或大规模训练。
- P2 使用真实 SFT 权重进行前向验收；后续从 LLM 初始化训练的能力需单独报告。

## 六、相比原项目的补充与修改清单

对照对象为只读本地 `minimind-o/model/model_omni.py` 和 `dataset/omni_dataset.py`，不是对未核对的上游版本作泛化结论。

| 原项目参考行为 | 本次补充或修改 | 审查位置 |
| --- | --- | --- |
| Omni 构造时加载 SenseVoice/SigLIP；用 `object.__setattr__` 保存编码器 | 编码器独立显式构造；注册为 `nn.Module`，可检查参数、设备和冻结状态 | `model_encoders.py` 的两个 Encoder |
| 音频和图像的占位/缺失判定部分依赖 Tensor 是否全零 | 保留按样本排列的特征列表和 `None`；全零有效特征不代表缺失 | 既有 `_inject_features`、Dataset/Collator；本轮真实混合 batch 验收 |
| 音频有效长度采用输入长度与输出长度的最小值 | 使用 SenseVoice Encoder 返回长度裁去 padding | `SenseVoiceEncoder.forward` |
| WavFrontend 默认 dither 可能使重复读取产生随机差异 | 固定 dither=0，实际重复音频和图像 bytes/path 编码对照 | Encoder 构造、`check_p2.py` |
| 外部模型加载可能未显式约束离线、缺失权重处理 | 已有本地目录、HF `local_files_only=True`；SenseVoice Encoder 与 Omni 均严格加载 | 两个 Encoder 构造、真实检查脚本 |
| 冻结参数后仍需要维护模块 eval/device 生命周期 | `.train()` 仍保持 eval，注册参数跟随 `.to()`；输出回调统一 CPU FP32 | `tests/test_encoders.py` |
| 缺少本项目对应的真实混合输入验收记录 | 增加四种组合、单样本/混合 batch、重排、padding 与有限值检查及资产 SHA-256 | `scripts/check_p2.py`、`experiments/p2/` |
