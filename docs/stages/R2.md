## 二、架构与 Tensor Shapes

```text
图片 → 冻结 SigLIP2 [64,768] → Vision Projector [64,2048] ┐
语音 → 冻结 SenseVoice [L,512] → Audio Projector [L,2048] ├→ 替换 user 槽位 [B,T,2048]
原生 Qwen Chat Template IDs [B,T] → Qwen token embedding ┘
       → 冻结 Qwen3-1.7B ┬→ 原生 final norm 与 LM head → 文本 logits [B,T,151936]
                         └→ Block 13 原始输出 [B,T,2048]
                             → FixedBridge [B,T,768]
                             + 延迟声码历史 [B,8,T]
                             → 4 层 × 768 Talker → 声码 logits [B,8,T,2112]
                             → 还原 8 路完整帧 → Mimi 流式 PCM
```

Bridge 使用 **零基 Block 13**（第 14 层）输出，位于 Qwen 最终 norm 之前。Bridge 内完成无 bias 线性投影、RMSNorm、padding 条件清零，Talker 内部投影置为 Identity。通过 `bridge=` 传入其他满足 `(hidden, valid) → condition` 的模块即可替换。当前选层是可复现的默认值，未做最优层或 Adaptive Bridge 实验。

Qwen 原生模板 `enable_thinking=False`。文本 PAD `151643`，回复 EOS `151645`。图像使用现有 `<|image_pad|>`（151655）；`<|vision_pad|>`（151654）仅在本项目中标识音频槽位。原始内容禁止直接写入这些保留标记或模板角色标记。每个槽位只注入一个有效特征，音频可变长，图像 64 个槽位。词表和官方权重保持原尺寸；tokenizer 151669 个 ID，LM head 151936 行。

## 三、真实样本与因果时间轴

数据来自既有 P4 小样本缓存，源 revision `d6588e12ac2ac8ced65eb58a7d7b3eef4aa220de`。真实 Smoke 按指纹选中 T2A 源行 7、14、0，A2A 行 31，I2T 行 91。A2T 诊断由该 A2A 用户音频与源记录的输入转写构造，和独立 A2T 数据集分开记。冻结编码器实测 `[60,512]` 和 `[64,768]`。另以本地锁定 tokenizer 转换全部历史 72 条 P4 记录，train/validation 批量音频标签形状为 `[64,8,425]` 与 `[8,8,340]`。这些是历史小样本，不能当作新的独立测试集。

下面的位置是 **零基 logits/标签位置**，区间两端均包含。对长度为 `P` 的前缀、`F` 个物理音频帧，第 `i` 路码本第 `f` 帧在 `P+i+f` 监督，在下一位置 `P+i+f+1` 才能作为历史输入；各路 STOP 在 `P+i+F`。该计算轴并不表示文字与 Mimi 12.5 Hz 物理帧一一对应。

| T2A 源行 | 前缀 P | 文本目标（末位 EOS） | F / 有效位置 T | 码本 0 帧 → STOP | 码本 7 帧 → STOP |
| --- | ---: | --- | --- | --- | --- |
| 7 | 19 | 18–25 | 26 / 53 | 19–44 → 45 | 26–51 → 52 |
| 14 | 18 | 17–28 | 42 / 68 | 18–59 → 60 | 25–66 → 67 |
| 0 | 19 | 18–129 | 300 / 327 | 19–318 → 319 | 26–325 → 326 |

三个样本分别产生 `[8,53]`、`[8,68]`、`[8,327]` 声码标签，整条时间轴均逐元素核对音频历史与标签，包括 prompt 不得混入答案声码。三条都恢复出原始 `[8,F]`。文本 EOS 后仍可监督音频；此时文本输入用 PAD，联合序列的 attention mask 仍为 1，文本标签设为 `-100`。批次补齐的真正 padding 设 mask 为 0，音文标签都设为 `-100`。无效占位、错误码本 ID 及超出长度上限的序列会报错，避免静默裁掉有效音频；全忽略 CE 回归为零。SFT 仍使用原有的每码本归一化和 STOP 加权，标签只 shift 一次。

对旧 A2A 源行 3 的审计发现参考声码与完整答案 54 帧逐元素相同。R2 仅默认使用 user 侧媒体，源记录的参考声码与 speaker 字段均不自动采纳。调用方可显式传入已核验的参考条件，formatter 拒绝可识别的连续重叠；R3-L 仍需按原媒体指纹与来源组审查跨样本重复和间接泄露。

## 四、冻结、梯度、Cache 与 PCM

本机 macOS arm64，Python 3.12.14、PyTorch 2.15.0、Transformers 4.57.6。真实 R2 在 CPU FP32、四线程、离线运行。Qwen revision `70d244cc86ccca08cf5af4e1e306ecf908b1ad5e` 的 12 个文件与 R1 资产锁一致，Qwen 和 Mimi 的加载检查没有缺失、多余或形状不匹配的权重键。SenseVoice、SigLIP2、Mimi 主权重 SHA-256 与历史记录匹配；从外置盘旧仓库只读加载，未下载资产。

| 模块 | 参数量 | 实测 |
| --- | ---: | --- |
| Qwen / SenseVoice / SigLIP2 / Mimi | 1,720,574,976 / 221,136,992 / 94,552,320 / 79,308,609 | 冻结，保持 eval，参数梯度为空 |
| Vision Projector | 5,772,800 | 6 个参数张量有非零梯度 |
| Audio Projector | 5,248,000 | 6 个参数张量有非零梯度；单独用音频损失反传，最大梯度约 0.08225 |
| Fixed Bridge | 1,573,632 | 2 个参数张量有非零梯度 |
| Talker（含 8 个头） | 45,868,802 | 86 个参数张量有非零梯度；未传 speaker 时对应分支无梯度 |

A2A/I2T 两样本前向产生 `[2,213,151936]` 文本和 `[2,8,213,2112]` 音频 logits，复用 SFT Loss：总计 14.67251（文本 6.22224、音频 8.45027、aux 0）。单独音频 Loss 经 Talker、Bridge 和冻结 Qwen 回到 Audio Projector；冻结权重不阻断对投影输入的梯度。A2A/I2T/A2T 三路混排后还原顺序，文本、音频 logits 的最大差均为 0。

Cache 使用每话轮独立的 Qwen `DynamicCache` 与 4 层 Talker KV。媒体只在 prefill 注入，后续传完整物理 mask，以有效位置计算两路的位置编号。新话轮传 `None` 重置。Cache 对比全量重放、左 padding 对比无 padding 使用 `rtol=1e-4, atol=1e-4`。真实行 0 的 327 个有效位置也通过前向；此处未测模型最大上下文容量。

| T2A 源行 | Cache 最大绝对差（文本 / 音频） | 左 padding 最大绝对差（文本 / 音频） | 扰动未来声码 → 更早音频 logits 最大差 |
| --- | --- | --- | --- |
| 7 | 5.56e-5 / 4.59e-6 | 5.01e-5 / 4.29e-6 | 从位置 24 起扰动 → 0 |
| 14 | 4.43e-5 / 4.65e-6 | 6.29e-5 / 5.84e-6 | 从位置 23 起扰动 → 0 |

26 帧和 42 帧真值声码的整段/分块 PCM 最大差分别为 1.30e-6、5.74e-7。独立使用 24 kHz 的 A2A 用户波形重编码得到 `[1,8,46]`，经 delay/restore 原码可逆。流式终止验收在真实模型前向后控制 logits，强制文本提前 EOS、逐路音频 STOP、预算截断与取消：正常结束产出 4+1 帧共 9,600 PCM 样本，和整段解码峰值差 2.87e-7；截断只交付已完成的 3 帧，取消会关闭上游。这一结果验证流式机制，随机 Talker 的语音内容与音质不作验收。
